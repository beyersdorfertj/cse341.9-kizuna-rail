## Commit messages

Use the Conventional Commits format `<type>: <subject>`. Allowed types are
`build`, `chore`, `ci`, `docs`, `feat`, `fix`, `perf`, `refactor`, `revert`,
`style`, and `test`.

For example, use `test: fix the failing case` instead of `test fix`.
